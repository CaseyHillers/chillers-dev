2025 was the year of agentic AI. This year was interesting as it was less for me about building big projects, and more so transitioning to a lot of smaller, targeted projects thanks to generative AI. It was a roller coaster starting off with one shot UI tools like Lovable, Cursor evolving to try and refactor large swaths of code, to finally codex enabling us to achieve such powerful agents.

Pre-LLMs, it was common for a proof of concept to be planned out as part of the project. SWEs went into the project knowing it had a decent chance that it would need to be productionized. So the foundations were put into place to be able to scale the codebase. POCs naturally matured into production apps, and engineers were very familiar throughout the process. The cost was still high, so a lot of people didn’t take risks. Nowadays, we truly have POCs we can throw away as a human didn’t spend much time on them. I personally will go through 3 different versions generated by AI to find which approach I like.

In April, at work we were able to create a proof of concept of a realtime conversational agent to help users kickstart their memories. Lovable was able to oneshot and create us a cool demo to show the team in 10 minutes validating our hypothesis on a good UX for this feature. The last 10% took 3 engineers 2 weeks fixing security issues, branding the web app with the company design language, and finishing the final integrations with our backend. This is one of the issues with AI generated POCs in that it can take us much more time to get it ready for production, and it can feel like an unfamiliar codebase.

I experimented with Metis, Arm’s security review agent, and had it review my team’s codebase for findings, and then tied it together with codex for fixes. It required some hand holding to help fine tune the security agent to avoid creating noise, but in the end a 2 week task took me 3 days. The real impact is that future teams will be able to only spend a day on it. This was a process of AI agents the whole way down. Metis generated its findings in JSON, so I had ChatGPT write a bash script to publish them to our GitLab instance. This helped give a place to review and comment on the issues for data analysis (such as actual findings, duplicates, hallucination). Afterwards, I was able to generate another bash script to pull these security issues from GitLab, and start codex instances to work on them. With this pipeline created, I was able to run it in the background on my workstation in a few hours for a 15K LOC codebase. The final part was human review of the MRs with the attached security finding. This combo made it really fast to validate whether we had actual security concerns. In the end, I accepted about half of the fixes, and I found the ones that were most applicable were less than 10 LOC diffs.

I recently came into a collection of 250 comic books from the 80s. I created an AI agent that can help me work on selling them. I took pictures of all the covers on my phone, and exported them to my computer for processing. The AI agent will classify the dataset with OCR models (Gemini was really good at this) to identify the title, issue number, and publisher. With the CSV put together, I asked it to group together comic books that should get sold together (saves me on time and effort for shipping). Then a research agent searched eBay for what the historical prices are for these comic books selling. It needed to evaluate if the listing was a bundle, and what the condition of the comic books was. I have low stakes in this, so I approved all the agent generated prices and had it create the listings on eBay. Finally the human in the loop part was monitoring my email for eBay notifications of purchase so I could ship them to the happy buyer. Overall, it was a fun project, and it only cost me $1 in tokens. Before, this would have been easily a week-long project where I would’ve just donated the comic books.

I’m really excited where agentic AI is heading in the next few months. Even in 6 months, it has grown a lot, and you can tell the foundational models are greatly improving at these multi-turn tool calls. I was limited by the enterprise environment, but I suspect you could simplify my security review workflow with an entire codex agent that has access to GitLab MCP and a SKILLs.md explaining how to use Metis. One thing is for sure and it's that SWEs are going to spend much less time writing code, and more time building.
